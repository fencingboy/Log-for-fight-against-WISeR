# WISeR Care Impact Tracker

A web application designed to gather verified, real-world user logs from patients and healthcare providers regarding prior authorization delays caused by the WISeR AI model. This tool supports Representative Suzan DelBene's legislative oversight efforts.

## Features
- **Clean Slate:** No fake accounts or mock data.
- **Dynamic Authentication:** Distinct Sign Up, Log In, and Sign Out logic.
- **Community Registry:** Public log viewing with live search filtering.
- **Privacy First:** Optional name and age fields for anonymized logging.

## Tech Stack
- HTML5 / CSS3 / JavaScript (ES6)
- Web Storage API (`localStorage`)

## Getting Started
Open `index.html` in any web browser, or host the repository directly using **GitHub Pages**.
